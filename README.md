# Family Style Planner

A full-stack web application that helps families organize outfit inspiration, home décor, recipes, event planning, and lifestyle ideas into customizable boards.

Built with **React**, **Django**, and **Django REST Framework**, Family Style Planner combines a modern user interface with a scalable backend architecture to create an intuitive planning experience.

> 🚧 **Currently under active development.** New features are being added regularly with the goal of releasing a public version in the future.

This is my UXUI Portfolio where I go into more details about this amazing project and soon to be a fully working application for many to use

## Overview

Family Style Planner is designed for families who want a simple way to save and organize inspiration for everyday life.

Users can create personal boards, save ideas, manage their profiles, and organize inspiration into meaningful collections—all within a clean, responsive interface.

## Running the Project

### Backend

```bash
cd backend

source ../venv/bin/activate

python manage.py migrate

python manage.py runserver
```

Backend runs at:

```
http://127.0.0.1:8000/
```

---

### Frontend

```bash
cd frontend

npm install

npm start
```

Frontend runs at:

```
http://localhost:3000/
```
